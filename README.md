
# SmartHire AI

Academic AI project prototype: Resume Analyzer & Job Matching System.

## Features
- PDF resume text extraction
- Skill matching
- Job keyword matching
- Compatibility score
- Missing-skill detection
- Resume improvement recommendations
- Interview question generation

## Run locally
```bash
python -m pip install -r requirements.txt
python app.py
```
Then open http://127.0.0.1:5000

## Tech Stack
Python, Flask, PyMuPDF, HTML, CSS, JavaScript-free server-rendered UI.

## Note
The prototype uses a transparent NLP-style matching algorithm rather than requiring a paid AI API, which makes it easy to demonstrate and deploy for an academic project.
